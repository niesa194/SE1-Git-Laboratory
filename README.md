# SE1-Git-Laboratory

A simple web page for the Software Engineering 1 Git and GitHub laboratory (PHINMA Saint Jude College Dasmariñas).

## Purpose
This project is only for practicing Git and GitHub: tracking changes with commits, working with branches, pushing to a remote repository and opening a pull request.

## Features
- Basic HTML page with a header and a content card
- CSS styling (layout and colors)
- A button that shows a welcome message based on the time of day (JavaScript)

## How to run
1. Clone the repository: `git clone < https://github.com/niesa194/SE1-Git-Laboratory.git>`
2. Open the folder `SE1-Git-Laboratory`
3. Double-click `index.html` (or open it in VS Code with Live Server)
4. Click the button to see the message

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - button interaction
- `.gitignore` - files Git should not track

## Git workflow used
`main` for the stable version, `feature/theme` (merged locally) and `feature/welcome-message` (merged through a pull request).
